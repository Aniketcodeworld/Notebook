1. How do you store passwords in the database?
Interview Answer

"We should never store passwords in plain text. Instead, passwords should be stored as one-way hashed values using a strong hashing algorithm like BCrypt.

When a user registers, I hash the password before saving it. During login, Spring Security compares the entered password with the stored hash using BCrypt."

Example:

@Bean
public PasswordEncoder passwordEncoder() {
    return new BCryptPasswordEncoder();
}

During Registration:

String encodedPassword =
passwordEncoder.encode(user.getPassword());

user.setPassword(encodedPassword);

userRepository.save(user);
